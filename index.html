YT Pipeline

YT Pipeline is a private tool used only by the owner of the YouTube channel Arise Manga. It creates educational data-visualisation videos (World Bank statistics, general-knowledge quizzes) and uses the YouTube Data API to:

  • upload and schedule those videos on the owner's own channel;
  • read the view, like and comment counts of the owner's own videos to improve future content.

It is not offered to the public and has no other users.
